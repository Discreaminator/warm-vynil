# Fonts (OFL)

Embedded in `WarmVynilUiData` for Variant B UI (SPEC §9.1.1).

| File | Family | License |
|---|---|---|
| `Inter-*.ttf` | Inter | OFL — see `LICENSE-Inter.txt` |
| `InterTight-Variable.ttf` | Inter Tight | OFL (Google Fonts) |
| `Geist-*.ttf` / `GeistMono-*.ttf` | Geist / Geist Mono | OFL — see `OFL-Geist.txt` |

Cyrillic UI strings use Inter / Inter Tight. Geist is used for numeric «Глубина» display; Geist Mono for numeric readouts (Cyrillic unit suffixes fall back via Inter in the editor chrome where needed).
